Engineering Academic Subjects Management System
This is a simple project written in C++ designed to help students view and query subject lists for different engineering college years, from Year 1 to Year 5 (Graduation Year).
How the Program Works:
When you run the program, it asks you to enter your academic year (from 1 to 5).
Based on the year you choose, it displays a list of available subjects for that year (such as Math, Physics, Data Structures, Networks, Graduation Project, etc.).
You select a subject number, and the program verifies your choice and displays a confirmation message.
Core Concepts Used:
Functions: Used to organize the code by placing each academic year in its own function (year1, year2, etc.).
Conditional Statements (if / else): Used to check user inputs and handle choices.
Basic I/O Operations: Using cin and cout for user interaction.
How to Run:
You can open this C++ code file in Qt Creator or any C++ IDE, then click Build & Run to start interacting with the program.
